# FDTD — To my dad.

아빠가 여행에서 직접 한마디 건넬 수 있도록, 가족이 준비하는 작은 영어 연습장.

현재 브랜드는 **FDTD (From Daughter, To My Dad)**. 화면의 주 문구는 **To my dad.**입니다. 프로젝트 폴더명은 `to-my-dad`입니다.

## 버전

현재 버전: **v0.1**. 변경 내역은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 첫 시안

- 화면 바깥은 남색 그라데이션. 문장마다 다른 상황 이미지 20장을 흰색 카드 안에 불투명도 32%와 3px 흐림 효과로 표시합니다.
- 그림과 중복 안내를 덜고, 카드 아래쪽 왼편에 < 와 작은 ‘힌트’, 오른편에 > 버튼을 배치했습니다.
- 첫 화면은 한글 질문 카드. 카드 아래에 “To my dad.” 소개가 이어집니다.
- 왼쪽으로 스와이프하면 현재 문장의 영어 답을 보여줍니다.
- 오른쪽으로 스와이프하면 다음 한글 질문 카드가 나옵니다. 다음 카드의 답은 다시 숨겨집니다.
- 버튼과 카드에 초점을 둔 좌우 방향키로도 같은 동작을 할 수 있습니다.
- 답 보기와 다음 카드 이동은 별개의 동작이며, 자동으로 ‘익힘’ 처리하지 않습니다.
- 영어 답을 펼친 후 발음과 힌트를 확인할 수 있습니다.
- 답 확인 횟수는 현재 페이지에서만 집계합니다.
- 전체 글꼴은 Pretendard를 사용합니다.
- 카드 안의 배경은 체크인·여권·통로 좌석·물잔·택시 등 각 문장의 구체적인 상황에 맞춰 전환됩니다.

## Lessons

1. 공항에서 — 체크인, 여권, 좌석 요청, 탑승구, 다시 말해달라고 하기
2. 호텔에서 — 예약, 체크인, 조식, 수건 요청, 체크아웃
3. 식당에서 — 메뉴, 추천, 주문, 물 요청, 계산
4. 길 위에서 — 말 걸기, 지하철역, 도움 요청, 택시, 감사 인사

각 레슨에 다섯 문장, 총 20개 카드를 넣었습니다.

## 보기

`index.html`을 브라우저에서 열면 됩니다. 별도 설치나 빌드가 필요 없습니다.
글꼴은 인터넷 연결이 있으면 jsDelivr에서 Pretendard를 불러오고, 없으면 기기 기본 글꼴로 표시됩니다.
