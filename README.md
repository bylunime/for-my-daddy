# FDTD, From Daughter To my Dad.

아빠가 해외 나가서 직접 한 마디 건넬 수 있도록, 딸이 준비하는 영어 연습장입니다.

**FDTD**는 **From Daughter, To my Dad**의 줄임말입니다.

## 시작하기

프로젝트 폴더의 `index.html`을 브라우저에서 열어 주세요. 별도 설치 없이 사용하실 수 있습니다.

## 카드로 연습하기

1. 한글 질문을 읽고 영어로 어떻게 말할지 떠올려 보세요.
2. 카드를 **왼쪽으로 넘기시거나** 왼쪽 **`<` 다음 장** 버튼을 눌러 영어 답을 확인해 주세요.
3. 영어 답 장에서 **발음 듣기**를 누르고 천천히 따라 말해 보세요. 필요한 경우 **말하기 힌트 보기**를 눌러 주세요.
4. 다시 왼쪽으로 넘기시면 다음 한글 질문이 나옵니다.
5. 앞 장을 다시 보시려면 **오른쪽으로 넘기시거나** 오른쪽 **`>` 이전 장** 버튼을 눌러 주세요.

**한글 질문 → 영어 답 → 다음 한글 질문 → 영어 답** 순서로 이어집니다. 질문과 답은 같은 배경 이미지를 사용합니다. 첫 장에서는 이전 장으로 이동하지 않습니다.

카드는 여러 장의 종이가 쌓인 모습으로 표시됩니다. 넘기는 종이는 살짝 옅어지고, 아래의 다음 장이 드러납니다. 짧게 끌었다 놓으시면 원래 자리로 돌아옵니다.

키보드를 사용하실 때는 Tab 키로 카드에 초점을 맞춘 뒤, 왼쪽 방향키로 다음 장, 오른쪽 방향키로 이전 장으로 이동하실 수 있습니다.

## 레슨 선택하기

상단의 **Lessons** 또는 **레슨 바꾸기**를 누르신 뒤, 연습하고 싶은 레슨을 선택해 주세요.

| 레슨 | 연습하실 내용 |
| --- | --- |
| 공항에서 | 탑승 수속, 여권 건네기, 좌석 요청, 탑승구 찾기, 다시 말해 달라고 부탁하기 |
| 호텔에서 | 예약 확인, 체크인, 조식 시간 묻기, 수건 요청, 체크아웃 |
| 식당에서 | 메뉴 요청, 추천받기, 주문, 물 요청, 계산 |
| 길 위에서 | 말 걸기, 지하철역 찾기, 도움 요청, 택시 이용, 감사 인사 |

각 레슨은 다섯 문장으로 구성되어 있으며, 총 20개 카드를 연습하실 수 있습니다.
레슨의 마지막 카드에서는 같은 레슨을 다시 보시거나 다음 레슨으로 이동하실 수 있습니다.

## 이용 안내

- 발음 듣기는 기기의 영어 음성을 사용합니다. 브라우저와 기기의 음성 설정에 따라 지원 여부와 목소리가 달라질 수 있습니다.
- 답 확인 횟수는 현재 페이지에서만 집계됩니다. 새로고침하시면 초기화됩니다.
- Pretendard 글꼴을 프로젝트에 포함하여 외부 글꼴 서버 연결 없이 표시합니다. 사용 허가 문서는 `assets/fonts/OFL.txt`에서 확인하실 수 있습니다.
- 매일 카드 내용을 바꾸는 기능과 외부 콘텐츠 API 연동은 아직 제공하지 않습니다.
